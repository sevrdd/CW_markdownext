# Extension Markdown
### Développeur: William Champagne 
### Scrum Master: Said Tarzalt
---
### But:
- Créer une extension à la librairie mistletoe qui permet de gérer certain paramètre d'une image dans un fichier markdown.
---
### Requis
1. Identification du raccourci (fonction)
2. Traitement et obtentions des données écrit par l'utilisateur (arguments)
3. Formatter le code HTML nécessaire (en utilisant les arguments) pour modifier l'image
4. Injecter le code HTML dans le fichier Markdown et ensuite convertir le fichier Markdown en HTML utilisant la librairie Mistletoe  

### Features (Priorisée)
1. Changer la taille de l'image.
2. Pouvoir déplacer l'image (Besoin de CSS)
3. Pouvoir faire une gallerie de photo (dépend de #2)
