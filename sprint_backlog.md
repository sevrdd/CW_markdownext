# Extension Markdown
### Développeur: William Champagne 
### Scrum Master: Said Tarzalt
---
### But:
- Utiliser les données obtenues dans le fichier markdown pour ensuite formatter le code HTML nècessaire à la modification de l'image. Convertir le fichier MD en HTML
---
### Requis
1. Extraire les arguments donnés par l'utilisateur
2. Insérer les données dans les lignes de code HTML permettant de modifier la taille de l'image
3. Injecter ces nouvelles lignes de code HMTL dans le fichier Markdown dans les emplacements appropriés.
4. Faire traduire le fichier markdown modifié en HTML utilisant la librairie mistletoe
5. Sauvegarder le fichier et tester/debug
